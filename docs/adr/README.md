# Architecture Decision Records

One short file per decision: `NNN-short-title.md`. Never edit an accepted ADR; supersede it with a new one.
The current decisions are summarised in [ARCHITECTURE.md §14](../ARCHITECTURE.md#14-architecture-decision-records).

## Template

```markdown
# NNN. Title

- Status: proposed | accepted | superseded by NNN
- Date: YYYY-MM-DD

## Context
What problem, which constraints (link PRD/ARCHITECTURE sections).

## Decision
What we do.

## Consequences
What gets easier, what gets harder, what we must watch.
```
